# Matt C. — Performance Creative Portfolio

Static portfolio website for Matt C. Individual ad artwork follows the layout and sequence of the original 2026 portfolio.

## Local preview

Run `python -m http.server 8000 --bind 127.0.0.1` in this directory, then open http://127.0.0.1:8000/.

## GitHub Pages

Publish from the `main` branch and the repository root. `.nojekyll` preserves the static assets without a Jekyll build.

Intended custom domain: **thatsmyportfolio.com**. Configure the domain in GitHub Pages before changing the domain's DNS records.
